# Data And Models

This folder points to the shared Full Cost Project source that supports the paper's constructed social-cost estimates for air and highway transportation: noise models, congestion models, intermodal comparison table material, and social-cost charts.

The actual original legacy formats, modern `.xlsx` conversions, and CSV exports are staged once at `../../../_shared_sources/full-cost-intercity-transportation-1996/`. The per-paper package is pointer-only for those repeated Full Cost files so they are not uploaded separately for each related paper.
