# Shared Full Cost Model Pointer

The Full Cost Project report/model files for this paper are staged once at `../../../../_shared_sources/full-cost-intercity-transportation-1996/`.

This per-paper folder is intentionally pointer-only. `data/DEDUP_POINTER_MANIFEST.csv` at the package root records the former package paths, shared-source paths, file sizes, and SHA-256 hashes.
